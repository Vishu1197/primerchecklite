# Release checklist

- [ ] Confirm maintainer name and repository URL.
- [ ] Review the license and citation metadata.
- [ ] Install from a clean virtual environment.
- [ ] Run `pytest`.
- [ ] Run `ruff check .`.
- [ ] Run CLI help and one valid example.
- [ ] Verify JSON and HTML report contents.
- [ ] Run Streamlit and test keyboard navigation and mobile layout.
- [ ] Review parameter names and thermodynamic assumptions against current primer3-py documentation.
- [ ] Review all citations.
- [ ] Check for secrets, local environments, and generated report files.
- [ ] Confirm that README claims match implemented and tested behavior.
- [ ] Add a tagged release only after maintainer review.
- [ ] Archive a release in an appropriate repository or software archive if a persistent citation is needed.
