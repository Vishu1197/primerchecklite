# Limitations

- No genome-wide off-target search is performed.
- Template matching requires exact sequence matches and does not model mismatches, variants, or indels.
- The template scan is a simple exact-match screen, not a full in silico PCR engine.
- Predicted Tm and structures depend on input chemistry and model assumptions.
- Warning thresholds are configurable heuristics, not universal PCR or qRT-PCR standards.
- The program does not design new primers, calculate qPCR efficiency from experimental data, or validate an assay.
- Do not use a clean report as evidence of specificity or successful amplification. Use suitable external specificity tools and experimental validation.
