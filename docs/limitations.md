# Limitations

PrimerCheck Lite is an early-stage research utility.

- It is not a genome-wide primer specificity search engine.
- Exact-match template screening does not permit mismatches, indels, or variants.
- A single supplied template is not a substitute for the correct reference genome or transcriptome.
- Predicted Tm and secondary structures depend on the thermodynamic model and input concentrations.
- The warning thresholds are configurable heuristics, not universal cutoffs.
- It does not guarantee amplification, specificity, yield, or absence of primer dimers in the laboratory.
- It does not replace primer design tools, NCBI Primer-BLAST, appropriate in silico PCR, or wet-lab testing.
- Initial support is limited to standard unambiguous DNA primer sequences for thermodynamic analysis.
- The software has not been clinically validated.

Use results as a review aid. Record software and dependency versions, sequence provenance, assay conditions, and experimental validation for research reports.
